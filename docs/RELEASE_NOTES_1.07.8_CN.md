# DeepSeek Harness Studio v1.07.8

> 版本：1.07.8 ｜ 发布时间：2026-08-24 ｜ [GitHub Release](https://github.com/Maskicruis/deepseek-harness-studio/releases/tag/v1.07.8)

本版本集中修复应用内更新下载和覆盖安装：不会再同时运行镜像与官方线路，也不会因连续点击造成多个任务争用同一个临时文件。

## 更新线路

- “自动”严格按顺序执行：国内镜像请求完全失败后，才尝试 GitHub 官方线路。
- 新增“仅国内镜像”；“仅 GitHub 官方”和“仅自定义镜像”也保证线路互斥。
- 自定义镜像失败时不再隐式连接 GitHub，便于受限网络环境准确控制流量。
- 所有线路仍以 GitHub Release 提供的 SHA-256 为可信校验值，校验失败的文件不能安装。

## 下载与安装稳定性

- 全局只允许一个安装包下载任务，重复点击会复用当前任务。
- 切换线路前关闭网络响应和 `.part` 文件句柄，再清理临时文件，避免 Windows 文件占用。
- 下载尚未完成时禁止启动安装程序；重复点击安装也只启动一次向导。
- 启动安装向导前先停止 Harness，随后退出 Studio，释放当前安装目录后再覆盖升级。

## 升级建议

旧版更新器若已经卡在下载中，请完全退出 Studio，然后直接运行本 Release 的 1.07.8 安装版覆盖原目录。安装时仍可自定义路径，不需要先卸载，也不会主动删除 `%USERPROFILE%\.dsh` 中的会话、插件和 Skills。
