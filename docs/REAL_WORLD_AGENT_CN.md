# 真实互联网搜索与 Windows 桌面控制

DeepSeek Harness Studio v1.09.0 为智能体提供两类“真实世界”能力：通过 DeepSeek 官方服务搜索当前互联网，以及在用户逐次批准后观察和操作当前 Windows 桌面。

## 实时联网搜索

1. 在 Harness 内部的模型设置中配置 DeepSeek 官方 API Key。
2. 直接提问，例如：“搜索今天 DeepSeek 的最新公告，说明发布日期并附上来源。”
3. 智能体会调用 `web_search`，工具卡片与搜索状态显示在当前对话中，回答会保留搜索结果的真实来源。

本版只启用官方搜索，不开放任意 URL 抓取。DSH 0.1.0-rc.7 的匿名 HTTP 抓取实现尚未提供完整的内网/SSRF 防护，因此 Studio 不会把它伪装成“安全抓取”交给模型。

## 启用真实桌面控制

1. 打开 Studio 右上角“偏好设置”。
2. 在“智能体能力”中打开“真实桌面控制”，然后保存设置。
3. Harness 会自动重启并将组件部署到当前用户的 `%USERPROFILE%\.dsh\profiles\web`。该路径根据当前电脑动态生成，不依赖开发机盘符或用户名。
4. 选择支持图片输入的模型，例如 DeepSeek V4 Flash Vision Exp；桌面截图需要视觉模型才能理解。
5. 在对话中提出具体任务，例如：“查看当前桌面，打开已经显示的记事本并输入一行测试文字。”

## 可用操作

- `computer_screenshot`：截取虚拟桌面，包括多显示器区域。
- `computer_list_windows`：读取当前可见顶层窗口的标题、进程和位置。
- `computer_focus_window`：将指定窗口切到前台。
- `computer_move_mouse`、`computer_click`、`computer_scroll`：移动、点击和滚动真实鼠标。
- `computer_type`：使用 Windows Unicode 输入事件键入文字，不读取或覆盖剪贴板。
- `computer_hotkey`：发送受限快捷键，例如 `CTRL+L`、`CTRL+S`、`ALT+F4`、`ENTER`。

## 审批与安全边界

- 功能默认关闭；打开开关只加载工具，不会立即控制电脑。
- 每一次截图、窗口读取、聚焦、鼠标或键盘动作都会在 Harness 对话中显示操作卡片，并等待一次性批准。
- 如果你拒绝、审批功能不可用或工具参数无效，操作不会执行；不存在静默放行。
- 智能体会先截图观察，执行最小动作，再截图验证结果。屏幕内容会发送给当前所选的视觉模型，请不要在敏感页面启用截图。
- 密码、验证码、API Key、支付、UAC 安全桌面和破坏性确认必须由用户亲自处理。
- Windows 安全桌面和部分管理员窗口可能阻止截图或输入，这是操作系统安全边界，不应绕过。

## 关闭功能

回到“偏好设置 → 智能体能力”，关闭“真实桌面控制”并保存。Harness 重启后不再加载这些工具；实时联网搜索不受影响。
