## 核心定位

一句话：把 DeepSeek Harness 装进一个真正好用的 Windows 桌面客户端。

副标题：开箱即聊、路径感知、社区插件、完整 Harness 能力，一处完成。

项目身份：非官方社区开源项目，基于 DeepSeek 开源 Harness 构建。

## GitHub 仓库简介

DeepSeek Harness Studio 是一个面向 Windows 的开源智能体桌面客户端。它提供现代化的会话界面、零配置默认工作区、聊天路径识别和社区插件中心，同时保留 DeepSeek Harness 的会话、工具、Skills、子智能体、权限与模型配置能力。

## 首发长文案

### 让 DeepSeek Harness 真正成为一款桌面应用

DeepSeek Harness 很强，但命令行和工作区配置会让不少用户停在第一步。于是我们做了 **DeepSeek Harness Studio**：一个非官方、开源、面向 Windows 的桌面客户端。

打开应用就能开始对话。第一次启动时，它会自动准备默认工作区，不再要求你先挑选目录；如果你在消息中写下 `E:\Project`、`C:/work/app` 或具体文件路径，客户端也会识别这个目标，并把已有目录加入工作区列表。

它不是套壳聊天页。底层运行的是完整 DeepSeek Harness：会话、模型、工具调用、权限模式、Skills、子智能体和任务上下文都保留。同时，我们加入了社区插件中心，可从 npm、GitHub 或本地目录导入插件，支持启用、停用、卸载和安装日志。

你可以把它当作：

- 一个开箱即用的本地 AI 智能体桌面端；
- 一个更直观的 DeepSeek Harness 管理界面；
- 一个可继续开发、换肤和扩展的 Electron / React 开源工程。

目前提供 Windows 安装版和便携版。欢迎试用、提交 Issue、贡献插件与界面改进。
