# DeepSeek Harness Studio v1.4.1

## 国内更新线路

- 新增“自动（国内优先）”下载模式，内置社区镜像失败后自动回退 GitHub 官方线路。
- 新增“仅 GitHub”和“自定义镜像”模式，团队可填写自建 gh-proxy HTTPS 前缀。
- 下载界面实时显示当前线路；线路失败后会清理临时文件并尝试下一条线路。

## 安全策略

- Release 版本与 SHA-256 仍以 GitHub 官方发布信息为可信来源。
- 国内镜像只负责传输安装包，不能绕过文件完整性校验。
- 任一线路发生 SHA-256 不一致时，该文件会立即丢弃；只有匹配官方校验值的安装包才能启动。

## 升级

v1.4.0 用户可在“偏好设置 → 软件更新”中直接检查并覆盖升级，无需卸载，也不会删除工作区、会话、插件、Skills 或 ModLens 配置。
